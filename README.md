# Amy

Amy is a natural-language command-line agent. State what you want in plain English in your terminal, and Amy figures out the concrete steps and runs them for you using the tools available on your system.

```
$ amy "commit and push all the latest changes"
$ amy "summarize this folder"
$ amy "compress this folder"
```

This project is in the design phase — no implementation yet. See:

- [`CONTEXT.md`](./CONTEXT.md) — the domain glossary (what a "Session", "Tool", "Permission Grant", etc. mean here)
- [`ARCHITECTURE.md`](./ARCHITECTURE.md) — the planned technical architecture and repository structure
- [`CODING-RULES.md`](./CODING-RULES.md) — coding rules for this project
